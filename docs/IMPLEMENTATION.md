## Acceptance evidence

Operational receipts belong under ignored `output/`, never in public history.
An unfinished or unavailable acceptance check stays unchecked.

Live model continuation evaluation is recorded separately from deterministic
fixtures. Production promotion requires reviewing those results. Existing
deployments may retain a legacy runtime with a context-only integration artifact
when replacing unrelated capabilities would widen the release scope.

The initial Ardent production rollout stopped at the managed-command admission fence.
Its authority-unavailable receipt is historical, not a current diagnosis; recheck
current enrollment and signed admission evidence before resuming. Managed
ownership can forbid legacy dispatch even when the authority is healthy. No
admission control was bypassed. The subsequent managed context-only rollout
completed individual production-profile acceptance on 2026-11-03. See
[reviewed Ardent and Magnus compatibility](MAGNUS.md). Isolated pilots use synthetic data,
no enabled channels, no scheduled work, and no external tool effects. Operational
receipts and the complete profile inventory remain private. A cached installation
inventory can lag a verified runtime; record that gap separately rather than
treating discovery or heartbeat timestamps as activation proof.
