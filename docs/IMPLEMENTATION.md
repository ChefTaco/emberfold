# Implementation and acceptance

## Delivery checkpoints

- [x] Core and compatibility extraction verified against original Ardent tests.
- [x] General, creative, and reflective synthetic continuity fixtures and repeated compaction pass.
- [x] CLI, HTTP contracts, provider adapters, and installed-package checks pass.
- [x] Ardent uses the package with additive metadata and previous-reader rollback coverage locally.
- [ ] Public source and versioned artifacts published and verified.
- [ ] Live service authentication, preparation, restart, and rollback verified.
- [ ] Dedicated Ardent pilot passes before sequential production rollout.

Operational receipts belong under ignored `output/`, never in public history.
An unfinished or unavailable acceptance check stays unchecked.

Live model continuation evaluation is recorded separately from deterministic
fixtures. Production promotion requires reviewing those results. Existing
deployments may retain a legacy runtime with a context-only integration artifact
when replacing unrelated capabilities would widen the release scope.
