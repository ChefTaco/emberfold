# Evaluation

`npm run evaluate` runs deterministic, synthetic preservation and continuation
probes. `node scripts/evaluate.mjs --live --config PRIVATE_CONFIG` additionally
uses configured models. Reports are written under ignored `output/evaluation/`.

Compare prepared context with full history, a recent window, ordinary summary,
and the legacy Ardent summary representation. Exercise five successive compactions
for general, creative, and reflective scenarios. Inspect exact references,
corrections, unresolved work, uncertainty, and whether a model can answer a
defined continuation question.

Report token estimates separately from provider measurements, provider/model
identity, latency, assertions and failures. Model billing cost and caching savings
remain unknown unless actual usage records are supplied. Fixed test summarizers
prove mechanical behavior only. Never label them semantic-quality evidence.

All mechanical preservation checks must pass. Semantic failures and regressions
against the legacy representation block production promotion until investigated.
Passing synthetic probes supports those scenarios, not a general accuracy claim.
